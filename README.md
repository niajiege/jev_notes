## 关于笔记中的数值

笔记里出现的所有概率、分数都来自 Notebook 内置的离线替身（`_FakeAnswer` / `_FakeResponse`），用于说明**返回的数据结构**和**阈值分支逻辑**。

离线替身不会分析输入，因此这些数值**不构成模型能力的证据**（不反映准确率、校准质量、延迟或成本）。笔记第六节对此有明确标注。
