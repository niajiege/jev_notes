## 关于笔记中的数值

两章笔记的数值来源不同，引用时请注意区分。

**task1（第一章）**：数值来自 Notebook 内置的离线替身（`_FakeAnswer` / `_FakeResponse`），用于说明**返回的数据结构**和**阈值分支逻辑**。离线替身不会分析输入，因此这些数值**不构成模型能力的证据**（不反映准确率、校准质量、延迟或成本）。

**task2（第二章）**：数值来自本机 live 模式下的实际调用输出或运行截图，出处逐条可查。其中《02 状态》一册未留存运行数值，该节只记录实验设计，不列概率。

即便如此，第二章的数值仍只是**少数样例上的观察**，样本量与标注集都不足，不能据此推断模型的准确率或校准质量。
