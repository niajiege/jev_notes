## 关于笔记中的数值

四章笔记的数值来源不同，引用时请注意区分。

**task1（第一章）**：数值来自 Notebook 内置的离线替身（`_FakeAnswer` / `_FakeResponse`），用于说明**返回的数据结构**和**阈值分支逻辑**。离线替身不会分析输入，因此这些数值**不构成模型能力的证据**（不反映准确率、校准质量、延迟或成本）。

**task2（第二章）**：数值来自本机 live 模式下的实际调用输出或运行截图，出处逐条可查。其中《02 状态》一册未留存运行数值，该节只记录实验设计，不列概率。

**task3（第三章）**：数值来自本机 live 模式运行 Notebook 写回的输出格，逐条与执行结果核对过；只在当次测到的地方给数，没跑到的分支只写机制。其中「批量 vs 逐条」的耗时与 token 是**单次快照**，不是性能结论。

**task4（第四章）**：18 篇里只有 03、04、05、07、10 五篇有 live 实测数值（截图或 Notebook 输出格）；01、02 两篇跑成了离线（输出为内置示例，不作为模型证据）
